# Rig Pulse

Rig Pulse is a Windows performance monitor for CPU, GPU, memory and game FPS. This is alpha software; readings and compatibility vary by hardware and game.

## Download

Download the latest app ZIP from [Releases](https://github.com/Rzeto23/Rig-Pulse/releases), extract it completely, and run `RigPulse.exe`. The `.sig` file is used by the automatic updater; it is not a separate installer. The app can check for signed updates without a GitHub account.

## Getting started

Rig Pulse runs in the Windows notification area. Open it from the tray, or select Exit to close it fully. The optional Intel PresentMon installer is offered during setup for FPS capture and may require administrator approval. CPU/GPU sensor availability varies. RTSS is a separately installed optional fallback that can be disabled in Settings > Game Capture.

The in-game HUD is a separate Windows window. Borderless mode or Windows fullscreen optimizations may be needed; exclusive fullscreen or anti-cheat systems can prevent overlays or FPS capture. Compatibility and account safety cannot be guaranteed; follow your game's rules.

Settings, FPS history and agreement acceptance are stored locally. Update checks contact GitHub and its download providers. For terms and privacy details, use the app's Rules, agreement and privacy screen.

This repository provides releases and user information; application source code is not published here.
